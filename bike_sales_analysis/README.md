# Bike Sales Analysis

## 📊 Overview

This project analyzes bike sales data to identify patterns and trends in customer demographics, income, age, and commute distance.

An interactive dashboard was created in Microsoft Excel to explore the data and present the analysis visually.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis

## 🔍 Analysis

The analysis explores:

- Average income by gender and bike purchase status
- Bike purchases across different age brackets
- Bike purchases by commute distance
- Customer purchasing patterns and demographics

## 📁 File

| File | Description |
|------|-------------|
| `bike_sales_analysis.xlsx` | Excel workbook containing the data analysis, pivot tables, charts, and interactive dashboard |

## 🎯 Project Objective

The objective of this project was to practice data cleaning, exploratory data analysis, and interactive dashboard creation using Microsoft Excel.
